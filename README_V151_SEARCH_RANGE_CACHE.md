- `versionCode 2026080152`

## 手机端问题

连续多次快速点击“下一首”可能导致应用进程直接退出，并且 Java 闪退报告为空。

## 本版修改

- 220 ms 内的连续上一首/下一首操作合并为一次最终跳转；
- MediaPlayer 创建、数据源打开和准备入口串行执行；
- 新播放请求取消旧媒体打开和搜索后台缓存任务；
- 释放播放器前移除监听器，再执行 stop/reset/release；
- 搜索 Range 缓存响应线程中断；
- Android 11 及以上在下次启动时读取系统进程退出记录，补充 Native crash、ANR、低内存和信号终止诊断；
- 保留 v151 的搜索 Range 分段缓存逻辑。
